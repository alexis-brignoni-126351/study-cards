# Study Index

Your active-recall learning environment. This is where you **drill it until it sticks** and **read deeper** via O'Reilly texts.

## Quick Start

Copy this from `templates/study-index-template.md` and customize:
- Add your sessions to Session Coverage Status
- Define Prerequisites Map for your learning path
- Track Coverage Decisions as you audit

## Commands

- `/study` - drill cards due today
- `/study audit session-N` - find gaps, create cards
- `/study ingest <mode>` - ingest transcript/text/file
- `/study due` - see upcoming cards
- `/study status` - progress overview

## Example Cards

See `study/concepts/` for three example cards:
- Bias-Variance Tradeoff (ML fundamentals)
- RAG Chunking Strategy (RAG concepts)
- Model Selection Framework (decision framework)

Study these to understand the format, then create your own or run `/study audit` to generate cards from session material.
